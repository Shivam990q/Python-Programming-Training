List Comprehensions

From Imperative Loops to Pythonic Elegance

02 / 24

In traditional languages, transforming a collection requires creating an empty accumulator, managing loop state, and repeatedly invoking append methods.

Traditional Imperative Way (Slow & Verbose)

# Filter even numbers and compute their squares numbers = [1, 2, 3, 4, 5, 6, 7, 8] even_squares = [] for x in numbers: if x % 2 == 0: even_squares.append(x ** 2) print(even_squares) # [4, 16, 36, 64]

Pythonic List Comprehension (Clean & 25-35% Faster)

# Direct mathematical set-builder notation numbers = [1, 2, 3, 4, 5, 6, 7, 8] even_squares = [x ** 2 for x in numbers if x % 2 == 0] print(even_squares) # [4, 16, 36, 64]

Under the Hood: Why is it Faster?

The for-loop calls the Python method .append() at every iteration, incurring attribute lookup and stack frame overhead. List comprehensions emit the specialized CPython bytecode instruction LIST_APPEND which appends directly to the C array without Python-level function call overhead.

Trainer Notes

Mention that in Python 3, list comprehensions have their own scope! Unlike Python 2, the loop variable x does NOT leak into the surrounding function or global namespace.

List Comprehensions

Anatomy & Execution Blueprint

03 / 24

Every list comprehension is composed of three fundamental structural blocks:

[ EXPRESSION for ITEM in ITERABLE (if FILTER_CONDITION) ]

1. Transformation (What)

The expression applied to each surviving element. Can be a calculation, a method call, or a tuple/dictionary constructor.

x.upper(), x * 10, (x, len(x))

2. Iteration (Source)

Traverses any iterable: list, tuple, string, range, or generator object.

for ch in "GLA_MATHURA"

3. Predicate (Filter)

Optional boolean gate. Only elements for which this evaluates to True reach the expression.

if len(word) > 4
Trainer Notes

Write an example on the board: extract only uppercase vowels from a string. Ask students to write it in 30 seconds on paper.

List Comprehensions

The Classic Interview Trap: if vs if-else

04 / 24

This is the #1 most tested syntax error trap in campus placement coding assessments.

Case A: Filtering Elements (Trailing if)

Filters items out. List length is ≤ original length.

nums = [1, 2, 3, 4, 5] res = [x * 2 for x in nums if x > 2] # Output: [6, 8, 10] (Only 3 elements kept)

Case B: Value Substitution (Leading if-else)

Ternary conditional expression. Length is ALWAYS equal to original.

nums = [1, 2, 3, 4, 5] res = ["EVEN" if x % 2 == 0 else "ODD" for x in nums] # Output: ['ODD', 'EVEN', 'ODD', 'EVEN', 'ODD']

Fatal Syntax Error Alert: Never write if-else at the end!

# WRONG: SyntaxError: invalid syntax res = [x * 2 for x in nums if x > 2 else 0] # ILLEGAL!

Rule: Trailing if is a filter (NO else allowed). If you need an else, it must form a ternary operator before the for clause!

Trainer Notes

Emphasize: 'If you want to choose WHAT value to put, put it in front. If you want to choose WHETHER to put anything at all, put it in the back!'

List Comprehensions

Nested Comprehensions & 2D Matrices

05 / 24

Reading order for nested comprehensions is identical to writing nested for-loops from outside in.

Example 1: Flattening a 2D Matrix (1D Result)

matrix = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ] # Order matches: for row in matrix: for val in row: flattened = [val for row in matrix for val in row] print(flattened) # [1, 2, 3, 4, 5, 6, 7, 8, 9]

Example 2: Matrix Transpose (2D Result)

# Transpose: swap rows and columns matrix = [[1, 2, 3], [4, 5, 6]] transposed = [[row[i] for row in matrix] for i in range(3)] print(transposed) # [[1, 4], [2, 5], [3, 6]]

Readability Golden Rule

If a nested list comprehension requires more than 2 levels of nesting, refactor it into explicit loops. PEP 8 strongly advocates readability over dense single-liners.

Trainer Notes

Have students draw the nested loops in C-syntax on their notebooks: outer loop = first 'for', inner loop = second 'for'. This eliminates 100% of matrix flattening confusion.

Built-in Companions

sorted() vs list.sort()

06 / 24

sorted(iterable, key=None, reverse=False)

  • Accepts ANY iterable (strings, tuples, sets, dicts, lists).
  • Returns a brand new sorted list.
  • Leaves the original collection completely untouched.
  • Safe to use inside list comprehensions!

list.sort(key=None, reverse=False)

  • Exclusively a method of list.
  • Sorts in-place (mutates original list).
  • Returns None! (Huge beginner trap).
  • Never do x = x.sort() (x becomes None!).
# Custom key sorting: sort strings by length, then alphabetically words = ["apple", "fig", "banana", "kiwi", "pear"] sorted_words = sorted(words, key=len) print(sorted_words) # ['fig', 'kiwi', 'pear', 'apple', 'banana'] # Sort descending by ASCII sum custom = sorted(words, key=lambda w: sum(ord(c) for c in w), reverse=True)
Trainer Notes

CPython uses Timsort (hybrid of merge sort and insertion sort) with O(N log N) worst-case time complexity and stable ordering guarantee.

Built-in Companions

enumerate(): Clean Index Tracking

07 / 24

Never write manual index counter variables or range(len(lst)) in Python. enumerate() provides clean, zero-overhead tuple generator pairing.

students = ["Aarav", "Bhavna", "Chirag", "Deepika"] # 1-based indexing for real-world user display via start parameter for rank, name in enumerate(students, start=1): print(f"Rank {rank}: {name}") # Using enumerate inside a list comprehension to filter by position odd_pos_students = [name for idx, name in enumerate(students) if idx % 2 == 0] # ['Aarav', 'Chirag']

Placement Pro-Tip

Interviewers specifically watch whether you write for i in range(len(arr)): or for i, val in enumerate(arr):. Using enumerate() demonstrates authentic Python idiomatic mastery.

Trainer Notes

Highlight the start=... keyword parameter. By default start=0, but passing start=1 saves an unnecessary idx + 1 inside the loop body.

Built-in Companions

zip() & The Unzipping Idiom

08 / 24

zip(*iterables) aggregates elements from each of the iterables in lock-step parallel pairs.

names = ["Alice", "Bob", "Charlie"] scores = [95, 88, 92] grades = ["A+", "B+", "A"] # Parallel iteration into a list of tuples report = [f"{n}: {s} ({g})" for n, s, g in zip(names, scores, grades)] # ['Alice: 95 (A+)', 'Bob: 88 (B+)', 'Charlie: 92 (A)'] # The Legendary 'Unzip' idiom via argument unpacking * pairs = [(1, 'a'), (2, 'b'), (3, 'c')] nums, chars = zip(*pairs) print(nums) # (1, 2, 3) print(chars) # ('a', 'b', 'c')

Silent Truncation Trap (Python < 3.10)

By default, zip() stops as soon as the shortest iterable is exhausted, silently dropping leftover data! In Python 3.10+, use zip(a, b, strict=True) to raise a ValueError if lengths mismatch.

Trainer Notes

Demonstrate how dict(zip(keys, values)) creates a dictionary in a single line. Students love this pattern.

Strings Deep Dive

String Literals & Raw Strings (r"...")

09 / 24

Python offers 4 distinct ways to define string literals:

Single & Double Quotes

Completely identical in performance. Choose whichever lets you avoid escaping the inner quote.

a = 'GLA "University"' # No escape needed b = "It's Pythonic" # No escape needed

Triple Quotes (Multi-line)

Preserves multi-line structure, newlines, and indentation verbatim. Standard for function docstrings.

sql = """SELECT * FROM students WHERE cgpa > 8.5;"""

Raw Strings: r"..."

Suppresses escape sequence processing. Backslashes are treated as literal characters. Indispensable for Windows file paths and Regular Expressions.

normal = "C:\\new_folder\\test" # \n becomes newline, \t becomes tab! raw = r"C:\\new_folder\\test" # Exactly as written: 18 characters!
Trainer Notes

Tricky question for students: Can a raw string end with an odd number of backslashes? Answer: NO! r"abc\" is a SyntaxError because Python's tokenizer still uses the backslash to escape the trailing quote.

Strings Deep Dive

String Immutability & CPython Memory Model

11 / 24

In Python, strings are strictly immutable. Once allocated in memory, their contents can NEVER be modified.

s = "GLA" print(id(s)) # e.g., 0x24a87b00 # Trying in-place item assignment: s[0] = "P" # TypeError: 'str' object does not support item assignment

Why are Strings Immutable?

  • Dictionary Keys & Hash Stability: Strings can be hashed (hash(s)). If they were mutable, dictionary lookups would break!
  • Thread Safety: Multiple threads can read shared strings without locks.
  • String Interning: CPython shares single memory instances of small strings.
s = "GLA" print(f"Initial id: {id(s)}") # Reassignment does NOT mutate; it creates a NEW string object! s = s + " University" print(f"New id: {id(s)}") # DIFFERENT MEMORY ADDRESS!

Efficiency Tip

Repeated concatenation in a loop (s += ch) has O(N²) quadratic complexity because it re-allocates memory at every step. Always collect in a list and use ''.join(list) for O(N) linear time!

Trainer Notes

Draw two boxes on the board representing memory addresses. Show the pointer moving to the new address while the old one awaits garbage collection.

Strings Deep Dive

Indexing: Dual-Directional Coordinate System

12 / 24

Every character in a Python string has both a non-negative forward index and a negative backward index.

Positive Index 0 1 2 3 4 5 6
Character P Y T H O N 3
Negative Index -7 -6 -5 -4 -3 -2 -1

Boundary Alert: IndexError

Indexing outside the range [-len, len-1] immediately raises an IndexError: string index out of range. Note: Slicing NEVER raises an IndexError!

Trainer Notes

Ask: 'What is s[-len(s)]?' -> Always the first character (index 0). What is s[-1]? -> Always the last character.

Strings Deep Dive

Slicing Mastery: s[start:stop:step]

13 / 24

Slicing extracts a substring using half-open intervals [start, stop).

Default Values & Forward Slicing

s = "GLA_UNIVERSITY" print(s[0:3]) # 'GLA' (stop 3 excluded) print(s[:3]) # 'GLA' (start defaults to 0) print(s[4:]) # 'UNIVERSITY' (stop defaults to len) print(s[::2]) # 'GAUIEST' (step of 2) print(s[2:100]) # 'A_UNIVERSITY' (NO ERROR!)

Negative Step & Reverse Tricks

# Inverting a string in O(N) print(s[::-1]) # 'YTISREVINU_ALG' # When step is negative: # start defaults to len-1, stop defaults to before index 0 print(s[5:1:-1]) # 'NU_A' # Directional Mismatch Trap: print(s[1:5:-1]) # '' (Empty string! start < stop with step < 0)
Trainer Notes

Highlight the Directional Mismatch Trap: If step is negative, start MUST be greater than stop, otherwise Python returns an empty string without an error.

Strings Deep Dive

String Operators: +, *, in

14 / 24

Concatenation (+)

Combines two strings. Requires BOTH operands to be str.

s = "GLA" + " " + "Mathura" # "GLA" + 10 # TypeError!

Repetition (*)

Multiplies string contents by an integer.

div = "=" * 10 # '==========' zero = "abc" * 0 # ''

Membership (in / not in)

Checks substring existence in O(N) Boyer-Moore-Horspool search.

"LA" in "GLA" # True "xyz" not in "GLA" # True

Placement Trivia

In Python, "" in "anything" is ALWAYS True! An empty string is a valid substring of every string (including another empty string).

Trainer Notes

Quiz the students: 'What does "" in "" evaluate to?' 90% will guess False. It evaluates to True.

String Methods (6 to 8)

Trimming: strip(), lstrip(), rstrip()

16 / 24

Trims leading/trailing whitespace (spaces, tabs, newlines) or a set of specified characters.

Default Whitespace Stripping

raw = " \\n\\t GLA Campus \\t\\n " print(repr(raw.strip())) # 'GLA Campus' print(repr(raw.lstrip())) # 'GLA Campus \\t\\n ' print(repr(raw.rstrip())) # ' \\n\\t GLA Campus'

Custom Character Set Stripping Trap

url = "www.gla.ac.in/home/" # strips ANY matching characters, NOT the substring! cleaned = url.strip("w./") print(cleaned) # 'gla.ac.in/home' # Common trap: text = "banana" print(text.strip("an")) # 'b' (strips all 'a' and 'n'!)
Trainer Notes

Clarify: strip() takes a SET of characters, not a prefix string! If Python 3.9+ prefix removal is desired, mention removeprefix() and removesuffix().

String Methods (9 to 10)

split() and join() Architecture

17 / 24

split(sep=None, maxsplit=-1)

# sep=None: splits on consecutive whitespace! s = "Python is awesome" print(s.split()) # ['Python', 'is', 'awesome'] # Explicit delimiter: csv = "101,Aarav,CSE,9.4" print(csv.split(",")) # ['101', 'Aarav', 'CSE', '9.4'] # maxsplit limits cuts: log = "2026-11-16 ERROR Database timeout occurred" parts = log.split(" ", maxsplit=2) # ['2026-11-16', 'ERROR', 'Database timeout occurred']

delimiter.join(iterable)

words = ["GLA", "University", "Mathura"] # Delimiter comes FIRST! sentence = " - ".join(words) print(sentence) # 'GLA - University - Mathura' # The TypeError trap: elements MUST be strings! ids = [1, 2, 3] # ",".join(ids) # TypeError: sequence item 0: expected str instance, int found valid = ",".join([str(x) for x in ids]) print(valid) # '1,2,3'
Trainer Notes

Emphasize why join is a string method and not a list method: because it works on ANY iterable of strings (tuples, sets, generators), not just lists.

String Methods (11 to 16)

Searching: find(), index(), count(), startswith()

18 / 24

The Critical Contrast: find() vs index()

s = "GLA_UNIVERSITY" # Substring exists: both return first index print(s.find("UNI")) # 4 print(s.index("UNI")) # 4 # Substring NOT found: print(s.find("XYZ")) # -1 (SAFE fallback) # s.index("XYZ") # ValueError: substring not found!

Rule of Thumb

Use find() when absence is normal; use index() when missing substring represents an error condition.

replace(), count(), startswith(), endswith()

msg = "banana banana" print(msg.count("an")) # 4 print(msg.replace("a", "o", 2)) # 'bonona banana' (max 2) # startswith / endswith accept a TUPLE of candidates! filename = "data_report.xlsx" is_valid = filename.endswith((".csv", ".xlsx", ".json")) print(is_valid) # True
Trainer Notes

Mention that startswith() and endswith() take a tuple, NOT a list. Passing a list raises a TypeError: tuple for startswith must only contain str.

String Methods (17 to 18 + extras)

Character Validation Methods

19 / 24

Boolean query methods to inspect string contents without regex overhead.

isdigit() vs isalpha()

"12345".isdigit() # True "12.34".isdigit() # False! (decimal point is not digit) "-50".isdigit() # False! (negative sign is not digit) "GLA".isalpha() # True "GLA 2026".isalpha() # False (contains space & digits)

isalnum() vs isspace()

"Batch2026".isalnum() # True (letters + numbers) "Batch#1".isalnum() # False (# is punctuation) " \\t\\n ".isspace() # True (all whitespace chars) "".isspace() # False (EMPTY string is NOT space!)

Empty String Rule

Every is...() method (e.g. isdigit(), isalpha(), isspace()) returns False on an empty string "" because there are zero qualifying characters.

Trainer Notes

Ask: 'How do you check if a user input string is a valid positive float?' Many students will say s.isdigit(). Show them why that fails and how to handle it properly.

Advanced String Methods

center(), zfill(), partition()

20 / 24

center(width, fill)

Centers string padded with fill character.

s = "GLA" print(s.center(11, "-")) # '----GLA----'

zfill(width)

Pads zeros from left; respects signs!

print("42".zfill(6)) # '000042' print("-42".zfill(6)) # '-00042'

partition(sep)

Splits into a 3-tuple: (before, sep, after).

email = "shivam@gla.ac.in" u, at, d = email.partition("@") # ('shivam', '@', 'gla.ac.in')

Why partition() is Safer than split()

split() returns a variable length list (length 1, 2, or more), requiring length checks before unpacking. partition() guarantees exactly 3 elements every time! If separator is missing, it returns (original_str, '', '').

Trainer Notes

Mention rpartition() which splits on the last occurrence of separator. Great for splitting filename and extension.

String Formatting

The 3 Eras of Python String Formatting

21 / 24

1. %-Formatting (Legacy)

Inherited from C printf.

name = "Aarav" cgpa = 9.284 res = "Hi %s, CGPA: %.2f" % (name, cgpa) # Clunky with tuples

2. str.format() (Python 2.6+)

Positional & named placeholders.

res = "Hi {0}, CGPA: {1:.2f}".format(name, cgpa) res = "{n} got {c}".format(n=name, c=cgpa)

3. Modern F-Strings (Python 3.6+)

Inlined expressions & fast execution.

res = f"Hi {name.upper()}, CGPA: {cgpa:.2f}" # Python 3.8+ Debugging syntax: print(f"{cgpa=}") # 'cgpa=9.284'
Trainer Notes

f-strings are not syntactic sugar; they are parsed into specialized CPython bytecode (FORMAT_VALUE) and run significantly faster than % or .format().

Placement & Interview Mastery

Top 10 Placement & Exam Traps Summary

23 / 24

Traps 1 to 5

  1. s[100] raises IndexError, but s[100:] safely returns "".
  2. [x for x in nums if x > 2 else 0] is a fatal SyntaxError.
  3. " ".join([1, 2, 3]) raises TypeError (must map to str).
  4. find() returns -1 when absent; index() raises ValueError.
  5. s.strip("abc") treats argument as a set of characters, not a sequence!

Traps 6 to 10

  1. "" in s is ALWAYS True for any string s.
  2. title() converts "it's" to "It'S".
  3. "" evaluates to False on isspace(), isdigit(), isalpha().
  4. s[1:5:-1] returns "" due to directional mismatch.
  5. list.sort() returns None; sorted() returns a new list.
Trainer Notes

Tell students to bookmark these 10 traps. In typical MCQs for placement drives, 60% of Python questions test these exact edge cases.
