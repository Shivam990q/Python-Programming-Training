Forenoon: Collections Deep Dive (42 Methods) • Afternoon: Functions, Scope & Functional Pipelines

Curriculum Ready • Day 2 Folder

📋 Day 2 Detailed Syllabus Breakdown

Master immutable tuples, unique sets, hash maps, parameter passing, and functional data transformations.

Session Core Modules Methods & Built-ins Covered Placement Traps & Key Takeaways
Forenoon (3 Hours)
Tuples, Sets & Dicts		 • Tuples: packing, unpacking, immutability
• Sets: hashing, Venn mathematical operations
• Dictionaries: key-value mapping, dict comprehensions, sorting by key/value 		• Tuple (12): count, index, min, max, sum, sorted, any, all, enumerate, reversed
• Set (15): add, update, remove, discard, union, intersection, difference, issubset
• Dict (15): get, keys, values, items, update, pop, popitem, setdefault, fromkeys 		• remove() raises KeyError on missing element vs discard() safe deletion.
• Dictionary mutation while iterating raises RuntimeError.
Afternoon (3 Hours)
Functions & Functional		 • Functions: definition, return, docstrings
• Arguments: positional, keyword, default, *args, **kwargs
• Scope: Local, Global, Nonlocal, LEGB Rule
• Functional: lambda, map(), filter(), reduce() 		• Higher-order functions: map(fn, iter), filter(fn, iter)
• functools.reduce(fn, iter) for accumulation
• Chaining pipelines: reduce(add, map(sq, filter(ev, nums))) 		• Mutable Default Argument Trap: def append_to(x, arr=[]) shares state!
• Modifying outer variables without nonlocal raises UnboundLocalError.

🔁 Day 3: Recursion, Modules & Packages

Forenoon: Recursive Problem Solving & Call-Stack • Afternoon: Standard Libraries, Custom Modules & NumPy

Curriculum Ready • Day 3 Folder

📋 Day 3 Detailed Syllabus Breakdown

Deconstruct the call-stack, master divide-and-conquer algorithms, and utilize Python's batteries-included ecosystem.

Session Core Modules Methods & Built-ins Covered Placement Traps & Key Takeaways
Forenoon (3 Hours)
Recursion Mastery		 • Base case vs recursive case architecture
• Call-stack mechanics & RecursionLimit
• Classic: Factorial, Fibonacci, GCD, Binary Search, Tower of Hanoi
• Memoization: custom dict cache & lru_cache 		• sys.getrecursionlimit() & sys.setrecursionlimit()
• functools.lru_cache(maxsize=None)
• Recursive traversal of nested lists and strings 		• StackOverflow: Missing base case exhausts CPython call stack (default 1000 frames).
• Overlapping subproblems in naive Fibonacci cause $O(2^n)$ exponential blowup.
Afternoon (3 Hours)
Modules & Libraries		 • Custom modules, import styles, __name__ == '__main__'
• Package structure with __init__.py
• Standard modules: math, time, os, random, datetime
• Scientific computing introduction: numpy arrays 		• math (12): sqrt, pow, ceil, floor, factorial, gcd, fabs, log, pi, e
• time (8): perf_counter, sleep, strftime
• os (12): getcwd, listdir, mkdir, path.join, path.exists
• random: randint, choice, shuffle, sample 		• Circular imports between two modules crash on initial execution.
• random.choice() on empty sequence raises IndexError.

Exception Handling		 • Errors vs Exceptions hierarchy
• try-except-else-finally complete flow
• Catching multiple exceptions & exception chaining
• raise, assert, and Custom Exception classes 		• Built-ins: ZeroDivisionError, ValueError, TypeError, IndexError, KeyError, FileNotFoundError

• finally block executes even if an unhandled exception or return occurs.
Afternoon (3 Hours)
File Handling		 • open() function and file modes: r, w, a, r+, rb, wb
• Context managers: with open(...) as f:
• Reading and writing text, binary, and CSV data

• seek(offset, whence) with tell() 		• Opening in w mode immediately truncates the file to 0 bytes before writing!
• Forgetting to close files causes resource leaks and uncommitted write buffers.
